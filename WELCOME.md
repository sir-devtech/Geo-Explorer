# Bem-vindo ao Geo-Explorer

Este projeto consulta trilhas fictícias de estudo, gera um desafio de código e emite um certificado fictício.

## Comandos

- `/trilha <tecnologia>` apresenta o plano de estudos. Exemplo: `/trilha Python`
- `/desafio <tecnologia> <nivel>` gera um desafio. Exemplo: `/desafio Python Basico`
- `/certificado <nome> <tecnologia>` cria o certificado. Exemplo: `/certificado "Ana Souza" "Python"`
- `/listar` mostra todas as trilhas disponíveis.

No terminal, o mesmo uso fica assim:

```bash
npm run geo -- trilha Python
npm run geo -- desafio Python Basico
npm run geo -- certificado "Ana Souza" "Python"
npm run geo -- listar
```

Tecnologias: Python, JavaScript, React, Java e TypeScript.

Níveis: Básico, Intermediário e Avançado.
